Field | experiment

Basic

Wrapping a plain input. No constraints — no errors will fire.

Required field

Submit the form empty to trigger a valueMissing error.

Type mismatch

Type something that isn't a valid email, then submit.

Pattern

Only lowercase letters and hyphens. Triggers patternMismatch.

Length constraints

Between 4 and 12 characters. Triggers tooShort or tooLong.

Custom error messages

The error prop overrides the default message per validity key.

Error message as function

Values in the error prop can be functions — useful when the message depends on runtime state.

Custom validity

setCustomValidity lets you attach any string key to the input. The error prop maps that key to a friendly message. Try typing WRONG and submitting.

Warning

Warnings appear when the field is valid but you still want non-blocking feedback. Type at least 8 characters to satisfy minlength, then change — the warning surfaces.

Textarea

Works the same with a <textarea> in the slot.

Select

Also works with a <select>.

Translation

The name attribute on <pap-field> scopes the translation lookup to fields.email.error.* before falling back to fields.global.*.
